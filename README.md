# Mac Commander Releases

Mac Commander 배포물(dmg)과 Sparkle appcast를 게시하는 리포입니다.
소스 코드는 비공개 리포(mac-commander)에서 관리합니다.

- 소개 페이지: https://codegeargit.github.io/mac-commander-releases/
- 최신 버전 다운로드: [Releases](https://github.com/codegeargit/mac-commander-releases/releases/latest)
- 자동 업데이트 피드(appcast): `https://github.com/codegeargit/mac-commander-releases/releases/latest/download/appcast.xml`
- 사용 약관: [EULA.md](EULA.md)

앱에 포함된 오픈소스 구성요소의 저작권·라이선스 전문은 앱의 **도움말 ▸ 오픈소스 라이선스**에서 볼 수 있습니다.
